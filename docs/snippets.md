# スニペット（定型文）設定リファレンス — `snippets.txt`

myahk_v2 のスニペット機能は、トリガー文字列を打つと本文に置き換える「テキスト展開」です（espanso や Lintalist の代替）。
設定は 1 つのテキストファイルだけで、コードの変更は要りません。このページは書式の完全な仕様です。
AI アシスタントに設定を頼むときは、このページを読ませてください。

## 1. ファイルの場所と反映

| 項目         | 内容                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 設定ファイル | `%USERPROFILE%\.myahk_v2\snippets.txt`（UTF-8。無ければスニペット機能は何もしない）                                        |
| ひな形       | [`config_samples/snippets.txt.sample`](../config_samples/snippets.txt.sample) をコピーして編集                             |
| 反映         | **ファイルは監視しない。** 編集したら Func メニュー（無変換 + S）の「スニペット再読込」を実行するか、myahk_v2 を再起動する |
| 編集を開く   | Func メニュー「スニペット設定を開く」（ファイルが無ければ空で作る）                                                        |

## 2. 書式

```
; 行頭が ; の行はコメント
[トリガー] ラベル
本文行 1
本文行 2
```

| 要素                       | 規則                                                                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 見出し `[トリガー] ラベル` | `[` で始まる行。`]` の後ろがラベル（候補メニュー・検索窓に出る説明。省略可）                                                      |
| 本文                       | 見出しの次の行から、次の見出しの直前まで。**前後の空行は除く。行末の空白は残す**（`git branch -d ` のような末尾スペースを保てる） |
| コメント                   | 行頭 `;`。本文の途中にあっても無視される                                                                                          |
| エスケープ                 | 本文の行頭を `;` や `[` にしたいときは `\;` `\[` と書く（先頭の `\` だけ外れる）                                                  |
| 同じトリガーを複数         | 候補メニューになる（順序はファイルの並び）                                                                                        |
| 文字コード                 | UTF-8（BOM の有無は問わない）。改行は CRLF / LF どちらでも可                                                                      |

例:

```
[;ymd]
{date:yyyy/MM/dd}

[;git] git branch -d ローカルブランチ削除
git branch -d

[;git] git worktree list
git worktree list

[;md] マークダウン テーブル
|     |     |
| --- | --- |
|     |     |
```

## 3. 本文で使えるトークン

| トークン                | 展開結果                                                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `{date}`                | 今日の日付を `yyyy/MM/dd` で                                                                                                          |
| `{date:書式}`           | 書式指定。AutoHotkey の [FormatTime](https://www.autohotkey.com/docs/v2/lib/FormatTime.htm) 書式（例 `yyyyMMdd`、`yyyy-MM-dd HH:mm`） |
| `{clipboard}`           | 展開時点のクリップボードの文字列                                                                                                      |
| `$\|$`                  | 貼り付け後にカーソルを置く位置。本文中 1 か所。1 行内なら正確、複数行では行数分ずれることがある                                       |
| `{input:名前}`          | 1 行の入力欄                                                                                                                          |
| `{input:名前=既定値}`   | 既定値つき。既定値に `{clipboard}` や `{date}` を書ける（先に展開される）                                                             |
| `{textarea:名前}`       | 複数行の入力欄                                                                                                                        |
| `{choice:名前=a\|b\|c}` | ドロップダウン。`\|` 区切りの選択肢、先頭が初期値                                                                                     |
| `{search}`              | この本文だけのトリガーは検索窓を開く（後述）。`{search:文字列}` でフィルタの初期値                                                    |

パラメータ（`input` / `textarea` / `choice`）の挙動:

- 1 つのスニペットにある分を**まとめて 1 つのフォーム**で聞く。フォームの上部にスニペット本文がそのまま表示される。
- **同じ名前は 1 回だけ聞き**、本文中の全箇所に同じ値が入る（種類が違っても名前が同じなら 1 つ）。
- キャンセル（Esc・×・キャンセルボタン）すると何も貼り付けない。
- 名前を省略した `{input}` は「入力」という名前になる。

例（パラメータつき）:

```
[;rep] 報告メール
{input:宛先} 様

{input:件名={clipboard}} の件、{choice:状況=完了|対応中|保留} です。
{textarea:詳細}

{input:宛先} 様、よろしくお願いします。
```

## 4. 発火と貼り付けの仕様

- トリガーは**打った直後に発火**する。終端文字（Space・Enter）は不要で、単語の途中でも発火し、大文字小文字を区別する（AutoHotkey ホットストリング `:*?C:`）。
- したがって、**あるトリガーが別のトリガーの先頭部分と一致すると、短い方だけが発火する**。`;git` と `;gitfix` を両方書くと `;git` の時点で反応し `;gitfix` には到達しない。新しいトリガーは既存トリガーと前方一致しないように決める（例: `;gitfix` → `;fix`）。
- トリガーに使う文字は英数字・記号を推奨。espanso 風に `;` で始めると日常の入力と衝突しにくい。
- 日本語 IME がオンのときは効かない（打った文字が変換中の文字列に入るため）。
- 貼り付け方: 本文が **1 行かつ 40 文字以下**なら文字入力として送る。それ以外はクリップボード経由で貼り付け、元のクリップボードは復元する。
- 候補が 1 つならそのまま貼り付け。複数ならカーソル位置に候補メニューを出す。

## 5. 候補メニューと検索窓

**候補メニュー**（同じトリガーが複数あるとき）

- 各行は「ラベル ｜ 本文の 1 行目（60 文字まで。複数行なら末尾に ⏎…）」。
- マウスを乗せる、または ↑↓ で選ぶと、右にツールチップで本文の全文が出る（40 行まで）。
- 末尾の「🔍 絞り込み…」で、そのトリガーの候補だけを検索窓に出す。

**検索窓**（本文が `{search}` のトリガー。ひな形では `;;`）

- 上の欄に空白区切りで語を打つと AND で絞り込む。対象はトリガー・ラベル・本文。
- 一覧は「トリガー ｜ ラベル ｜ 本文の 1 行目」。下の欄に選択中の本文がそのまま出る。
- ↑↓ で選び、Enter またはダブルクリックで、検索窓を開く前にアクティブだったウィンドウへ貼り付ける。Esc で閉じる。

## 6. AI アシスタントが設定を追加・変更するときのチェックリスト

1. `%USERPROFILE%\.myahk_v2\snippets.txt` を開く（無ければ `config_samples/snippets.txt.sample` からコピーする）。
2. 追加するトリガーが、既存のどのトリガーとも前方一致しないことを確認する（`;git` があるなら `;gitx` は不可）。
3. `[トリガー] ラベル` と本文を末尾（または関連する区画）に追記する。本文の行頭が `;` `[` になる行は `\;` `\[` にする。末尾スペースが必要なら残す。
4. 複数候補にしたいなら同じトリガーの見出しを並べる。パラメータが要るなら `{input:...}` などを本文に書く。
5. 利用者に「無変換 + S → スニペット再読込」を案内する（または myahk_v2 を再起動する）。
6. 動作確認は利用者の打鍵で行う。AutoHotkey スクリプトからの `Send` ではホットストリングが発火しない。
